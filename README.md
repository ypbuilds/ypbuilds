# Welcome to your YP Builds project

This project was built for YP Builds.

## Build
You can start building your project locally.

- **Fast & Modern**: Uses React, Vite, and TanStack Start.
- **Maintainable**: Built with standard tooling for easy future modifications.
## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
